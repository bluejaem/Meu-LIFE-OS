# Planner TI Life OS

Este projeto é um app estático em HTML/CSS/JS, compatível com hospedagem em GitHub Pages.

## Como publicar no GitHub Pages

1. Faça commit do projeto no repositório GitHub.
2. No GitHub, vá para Settings > Pages.
3. Configure a fonte para `Deploy from a branch` e selecione a branch principal (`main` ou `master`) com a pasta `/`.
4. Salve e aguarde a publicação.

O site ficará disponível no domínio `https://<seu-usuario>.github.io/<seu-repositorio>/`.

## Observação

- O app roda como site estático. Não há backend nem dependência de servidor Node para a versão publicada no GitHub Pages.
- Para uso local, abra o projeto em um servidor estático ou use o GitHub Pages para acessar diretamente via domínio.
